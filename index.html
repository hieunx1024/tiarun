Khởi chạy ứng dụng và tìm kiếm bằng bàn phím

Mở nhanh bằng phím tắt. Tự động khớp tiếng Việt không dấu (gõ tai lieu tìm Tài liệu), duyệt file kèm bảng xem trước, chuyển cửa sổ và lưu lịch sử clipboard hoàn toàn trên máy cục bộ.

Phím tắt mặc định: Ctrl+Alt+Space
Single-instance Daemon

Tiến trình nền duy nhất lắng nghe qua IPC (Unix socket / loopback port), hiện cửa sổ ngay khi nhận phím tắt mà không khởi động lại engine.

Fuzzy Search Không Dấu

Thuật toán SkimMatcherV2 kết hợp bộ chuẩn hóa ký tự tiếng Việt: gõ tai lieu tìm Tài liệu, ke hoach tìm Kế hoạch.

File Preview & Quét Nội Dung

Tiền tố @f lọc file kèm bảng xem trước bên phải; @t quét nội dung bên trong file văn bản và tài liệu Word (.docx).

Gói Cài Đặt & Portable

Hỗ trợ bộ cài hệ thống và bản nén portable cho Windows (Inno Setup / zip) cùng Linux (Debian .deb / tar.gz) kiến trúc x86-64.

Kỹ thuật & Vận hành

Những thông tin cốt lõi về cơ chế hoạt động nội tại của TiaRun.

Quyền riêng tư

Xử lý hoàn toàn cục bộ (Local-first)

Toàn bộ quá trình quét ứng dụng, lập chỉ mục file và lưu lịch sử clipboard đều chạy trên máy của bạn. Không gửi telemetry, không kết nối máy chủ phân tích và không đồng bộ dữ liệu ra ngoài.

Hiệu năng

Cơ chế Single-instance Daemon

TiaRun tạo cửa sổ một lần và duy trì tiến trình nền qua Unix domain socket (Linux) hoặc loopback TCP (Windows). Lần gọi sau chỉ gửi tín hiệu toggle qua socket, không tốn thời gian khởi tạo lại GPU context.

Công nghệ

Động cơ Rust & Slint GUI

Viết hoàn toàn bằng Rust và framework UI Slint với bộ dựng OpenGL / FemtoVG (tự động fallback phần mềm trên Windows khi thiếu driver), hỗ trợ hai phong cách hiển thị Liquid Glass và Classic.

Cấu hình

Tệp cấu hình TOML minh bạch

Mọi cài đặt gồm đường dẫn index, độ sâu thư mục (depth) và danh sách loại trừ lưu tại ~/.config/tiarun/config.toml (Linux) hoặc %APPDATA%\tiarun\config.toml (Windows).

Biên dịch từ mã nguồn (Rust)

Cần Rust toolchain phiên bản ổn định (stable) và Cargo. Cài đặt các thư viện đồ họa hệ thống trên Debian / Ubuntu:

sudo apt install build-essential pkg-config libxkbcommon-dev libxkbcommon-x11-dev \
  libfontconfig1-dev libwayland-dev libegl1-mesa-dev libgl1-mesa-dev libx11-dev libx11-xcb-dev

Clone repository và biên dịch bản release tối ưu:

git clone https://github.com/hieunx1024/tiarun.git
cd tiarun
cargo build --release --locked

File thực thi sau khi biên dịch nằm tại target/release/tiarun (Linux) hoặc target\release\tiarun.exe (Windows).
